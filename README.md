Personal Finance Dashboard:
A Python-powered Personal Finance Dashboard to help you track your income, expenses, investments, and visualize your financial health. The dashboard provides interactive widgets and graphs for analyzing your financial data, and is built using Panel, Pandas, and Matplotlib for data processing and visualization.

Features:
Track Income & Expenses: Easily track your sources of income and your daily/recurring expenses.

Visualize Spending Patterns: Visual representation of your spending trends with interactive graphs.

Expense Categorization: Categorize your transactions for better insights into where your money goes.

Dark Mode Theme: The dashboard can be switched to dark mode for a comfortable viewing experience.

Interactive Widgets: Use dropdowns and tables to filter data dynamically.

Technologies Used:
Python 3.x

Panel – A high-level app and dashboarding library for Python

Pandas – Data analysis and manipulation

Matplotlib/Plotly – Data visualization

Jupyter Notebooks (optional for quick experimentation)
