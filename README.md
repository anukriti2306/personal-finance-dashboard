# 💰 Personal Finance Dashboard

A **Python-powered dashboard** to help you track income, expenses, and investments, while visualizing your overall financial health. Built using **Panel**, **Pandas**, and **Matplotlib**, this tool offers interactive graphs and widgets for a personalized and insightful financial analysis experience.

---

## 🚀 Features

- **📊 Track Income & Expenses**  
  Log and monitor your sources of income along with daily or recurring expenses.

- **📈 Visualize Spending Patterns**  
  Analyze your financial trends using interactive and dynamic graphs.

- **📂 Expense Categorization**  
  Group transactions into categories for better insights into spending habits.

- **🌙 Dark Mode Support**  
  Toggle between light and dark themes for comfortable viewing.

- **🧩 Interactive Widgets**  
  Filter and explore your financial data in real-time using dropdowns and tables.

---

## 🛠️ Technologies Used

- **Python 3.x** – Core language  
- **[Panel](https://panel.holoviz.org/)** – High-level dashboarding and app framework  
- **Pandas** – Data manipulation and analysis  
- **Matplotlib / Plotly** – Financial data visualization  
- **Jupyter Notebooks** *(optional)* – For quick experimentation and prototyping

---

## 📦 Installation

1. **Clone the repo:**
   ```bash
   git clone https://github.com/yourusername/personal-finance-dashboard.git
   cd personal-finance-dashboard
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the dashboard:**
   ```bash
   panel serve finance_dashboard.py
   ```

> Make sure to update the data file paths and config based on your local setup.
